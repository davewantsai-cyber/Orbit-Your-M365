WHAT IT DOES

🔐

Secure credential storage

Tenant ID, App ID, and secrets stored in your OS keychain. Never written to disk in plaintext. Never passed as visible process arguments.

🛡️

Tool integrity checking

SHA-256 hash verified against a bundled manifest before any tool launches. A mismatch is a hard stop — no silent failures.

⚡

One-click orchestration

Runs ScubaGear, Maester, Monkey365, ROADtools, and Hawk in sequence. Live streaming logs. Clean cancellation at any point.

📊

Unified scoring

All findings normalised to a single model. Weighted risk matrix (Critical ×10 / High ×7 / Medium ×4 / Low ×1) produces a 0–100 posture score.

📄

Executive PDF / DOCX report

Cover page, posture score bar, top findings with CVE references and remediation steps, full findings table. Ready to hand to a client.

📧

Email on completion

SMTP delivery via your own mail server. HTML summary body, PDF attached. To + CC fields. Fires automatically when the run finishes.

QUICK INSTALL

Requirements

Python 3.10+, PowerShell 7+ (for ScubaGear / Maester / Monkey365), Windows recommended for full tool support.

git clone https://github.com/OrbitalSecurity/OrbitM365.git
cd OrbitSecurityM365
pip install -e .
orbit --dry-run

The --dry-run flag launches the full TUI with sample data — no tenant or credentials needed.

PRIVACY & SECURITY

🔒

100% client-side

No data is transmitted anywhere. No analytics, no telemetry, no update pings.

🗝️

OS keychain storage

Credentials stored in Windows Credential Manager, macOS Keychain, or libsecret.

✅

Integrity verified

SHA-256 hash checked against bundled manifest before any tool is launched.

📂

You control the output

Reports written only to the folder you choose. Optional AES-256 encryption.

⚖️

Authorised use only

Run only against tenants you are authorised to assess. See LEGAL.md.
